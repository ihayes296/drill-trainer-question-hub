## Overview

Drill Trainer is built for candidates working toward aptitude-focused technical assessments. Its question collection covers quantitative reasoning, deductive logic, algorithms, machine learning, programming, estimation, and other subjects commonly encountered in assessment preparation.

The application supports quick topic drills as well as sessions that resemble an exam. Users can answer questions against the clock, return to challenging subjects, read complete solution walkthroughs, and rely on spaced-repetition scheduling to strengthen retention. Progress remains in browser storage, and the offline-ready single HTML file avoids the need for a complicated installation process.

## How to Use It

For a structured practice run:

1. Launch Drill Trainer in your browser.
2. Pick **Drill** for focused exercises or **Exam** to simulate timed assessment conditions.
3. Choose either a mixed question set or a weaker subject area.
4. Submit answers and let the application check them automatically.
5. Read the worked solution and associated technique tags.
6. Return later through **Review**, using spaced repetition to schedule additional practice.
7. Open **Progress** to see activity and determine where further study is useful.

The **Techniques** mode is available when the goal is to learn the approaches used in the solutions without completing a full practice session.

## Configuration and Stored Data

There is no separate configuration file. Drill Trainer uses its browser interface for session selections, review details, and progress, storing that information in browser storage.

To reset the application on a device, remove its stored site data through the browser settings and reopen the HTML file. This also deletes the progress saved for that local application state.

## Frequently Asked Questions

### What kind of learner should use Drill Trainer?

Drill Trainer is aimed at people preparing for aptitude-style technical assessments. Its practice areas include quantitative reasoning, deductive logic, algorithms, machine learning, programming, and estimation.

### Is there anything to install?

No installation is needed. Use the hosted application in a browser, or download the standalone HTML file and open it directly on your device.

### Where does my progress go?

The application saves progress in the browser's local storage. A different browser, browser profile, or cleared site-data record can produce a separate or empty progress state.

### Are timed exercises available?

Yes. Individual questions are timed, and **Exam** mode provides a broader timed assessment-style workflow.

### How can I work on topics I find difficult?

Create a drill covering your weakest areas or use a mixed set, then revisit those questions in **Review** mode. Spaced repetition schedules material for later reinforcement.

### What can I try if the application is not behaving properly?

Make sure JavaScript is enabled, use a current browser, and reload the HTML file. If saved progress is not visible, verify that you are using the same browser profile and that its stored data has not been removed.
